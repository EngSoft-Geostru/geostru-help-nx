# Scorciatoie tastiera

Lista completa dei tasti di Trispace NX. UI in italiano → tasti seguono la
**prima lettera della parola italiana**.

## Tool DRAW

| Tool | Tasto |
|---|:---:|
| Linea | **L** |
| Polilinea | **P** |
| Punto / Quotato | **N** |
| Cerchio | **G** |
| Arco | **A** |
| Testo | **T** |
| Sezione | **S** |

## Tool MODIFY

| Tool | Tasto |
|---|:---:|
| Sposta | **M** |
| Copia | **C** |
| Specchia | **Y** |
| Ruota | **R** |
| Trim | **T** |
| Estendi | **X** |
| Offset | **O** |
| Stretch | **E** |

## Tool VIEW / UTIL

| Tool | Tasto |
|---|:---:|
| Selezione (esce dal tool) | **Esc** |
| Pan (temporaneo, mentre tieni premuto) | **Spazio** |
| Distanza (tra 2 punti) | **D** |
| Zoom estensione | **Ctrl + 0** |
| Zoom selezione | **Ctrl + Alt + 0** |
| Pan al centro | **Home** |

## Generale

| Azione | Tasto |
|---|:---:|
| Undo | **Ctrl + Z** |
| Redo | **Ctrl + Y** |
| Select All | **Ctrl + A** |
| Copy | **Ctrl + C** |
| Paste | **Ctrl + V** |
| Cut | **Ctrl + X** |
| Salva nel browser | **Ctrl + S** |
| Salva con nome (.cadproj) | **Ctrl + Shift + S** |
| Apri | **Ctrl + O** |
| Nuovo | **Ctrl + N** |
| Cancella selezione | **Del** |

|---|:---:|
