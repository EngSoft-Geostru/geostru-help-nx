# Data sources and limits

## The sources

Hydrogeo NX uses only data published by official bodies. Every station shows its source in
its sheet.

| Source | Area |
|---|---|
| **ISPRA** — Hydrological Annals | All of Italy (the main historical source) |
| **SIR** — Regional Hydrological Service | Tuscany |
| **ARPAS** — Regional Environmental Protection Agency | Sardinia |
| **ARPACAL** — Multi-hazard Functional Centre | Calabria |
| **Regione Lombardia** — Open Data | Lombardy |
| **Regione Marche** — Civil Protection, Multi-hazard Functional Centre | Marche |
| **ARPAV** | Veneto |
| **Protezione Civile Puglia** | Apulia |
| **SIAS** — Sicilian Agrometeorological Information Service | Sicily |
| **Regione Umbria** — Hydrographic Service | Umbria |
| **Centro Funzionale RAVDA** | Aosta Valley |
| **Autonomous Province of Bolzano** — Open Data | South Tyrol |

The app's **?** button shows the current number of stations, regions and the first year
available.

## The limits

- **Data as published.** Hydrogeo NX does not correct, fill in or estimate values. An error
  in the source stays in the data.
- **Recent years.** The latest years may not yet be validated, or not yet published, by the
  source.
- **Durations.** Historical stations often have only the 24-hour maximum; short durations need
  a recording rain gauge. The tables show durations from 1 to 24 hours and from 1 to 5 days,
  even when the sheet lists sub-hourly durations.
- **Daily rainfall only.** Some stations, for instance the SIAS stations in Sicily, have daily
  rainfall only: no series of maxima by duration, so no rainfall curve from that station.
- **Coordinates.** Some historical stations have no coordinates and do not appear on the map.
- **Apparent duplicates.** The same town can have several stations with similar names (for
  instance an old Annals station and the new regional one). They are different stations:
  compare period and source.

## Is your area missing?

If you need a source that is not there, or a station you know does not appear, write to
[info@geostru.ai](mailto:info@geostru.ai?subject=Hydrogeo%20NX%20-%20sources) or open a
ticket from the [assistant](assistente.md).
