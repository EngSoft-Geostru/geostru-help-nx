# Glossario

| Termine | Significato |
|---|---|
| A~0~ | ampiezza del picco della curva H/V |
| Componenti | NS, EO e V: le tre direzioni di registrazione |
| Ellitticità | rapporto fra spostamento orizzontale e verticale di un'onda di Rayleigh; è la curva H/V teorica del modello |
| f~0~ | frequenza del massimo della curva H/V |
| Finestra | tratto di registrazione su cui si calcola uno spettro |
| F~s~ | frequenza di campionamento |
| H/V | rapporto fra lo spettro orizzontale e quello verticale |
| Lisciamento | media pesata dello spettro attorno a ogni frequenza |
| l~w~, n~w~ | durata di una finestra e numero di finestre incluse |
| Misfit | disadattamento di forma fra curva misurata e ellitticità del modo fondamentale |
| Modo | soluzione di propagazione: il fondamentale è il modo 0 |
| Semispazio | ultimo strato del modello, di spessore infinito |
| SESAME | progetto europeo che ha pubblicato le linee guida del 2004 sulla tecnica H/V |
| σ | dispersione delle H/V fra le finestre, relativa alla curva media |
| σ~A~, σ~f~ | nel testo SESAME: fattore di dispersione dell'ampiezza e deviazione standard di f~0~ fra le finestre |
| STA/LTA | rapporto fra media breve e media lunga dell'ampiezza: rivela i transitori |
| Taper | finestra che porta a zero gli estremi del segnale prima della trasformata |
| Tromografo | sensore a tre componenti per la misura del rumore ambientale |
| V~s~ | velocità delle onde di taglio |
| V~s,eq~ | velocità equivalente delle onde di taglio, NTC 2018 §3.2.2 |
