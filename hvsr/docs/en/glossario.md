# Glossary

| Term | Meaning |
|---|---|
| A~0~ | amplitude of the H/V curve peak |
| Components | NS, EW and V: the three recording directions |
| Ellipticity | ratio between the horizontal and vertical displacement of a Rayleigh wave; it is the model's theoretical H/V curve |
| f~0~ | frequency of the maximum of the H/V curve |
| Window | stretch of recording on which a spectrum is computed |
| F~s~ | sampling frequency |
| H/V | ratio between the horizontal and the vertical spectrum |
| Smoothing | weighted average of the spectrum around each frequency |
| l~w~, n~w~ | duration of a window and number of included windows |
| Misfit | mismatch in shape between the measured curve and the fundamental-mode ellipticity |
| Mode | propagation solution: the fundamental is mode 0 |
| Half-space | last layer of the model, of infinite thickness |
| SESAME | European project that published the 2004 guidelines on the H/V technique |
| σ | scatter of the H/V across windows, relative to the mean curve |
| σ~A~, σ~f~ | in the SESAME text: amplitude scatter factor and standard deviation of f~0~ across windows |
| STA/LTA | ratio between short and long amplitude averages: reveals transients |
| Taper | window that brings the signal ends to zero before the transform |
| Tromograph | three-component sensor for ambient noise measurement |
| V~s~ | shear-wave velocity |
| V~s,eq~ | equivalent shear-wave velocity, NTC 2018 §3.2.2 |
