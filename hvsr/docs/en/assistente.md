# AI assistant

The **Assistant** button at the top opens the chat. The assistant works on the open project: it reads curve, checks and model, explains the numbers and sets the data you ask for. The
numbers come from the app's tools, not from the language model: the calculations are done by the engine.

The **Quick actions** offer "Project status", "Check the peak and SESAME", "Explain the category and its limits", "What is missing before the report?" and "Open a support ticket".

## What it can do

- read the project, the traces, the windows, the spectrum, the H/V curve, the model and the results;
- explain an outcome, a suggestion or a difference between two models;
- fill in the general data and set the spectrum parameters;
- generate the windows, include or exclude them and apply the transient filter;
- choose which SESAME criteria to read;
- write the model and synthesise it.

## What it does not do

- **It does not run the Search**: it points you to the button, which remains the only paid path.
- **It does not delete** the traces.
- **It does not replace** layers you already have, unless you explicitly ask.

While it works, a strip warns you and other changes are suspended. Every successful message uses credits; if there is an error you do not pay. Always check what it proposes: it is an
artificial intelligence system and can make mistakes.
