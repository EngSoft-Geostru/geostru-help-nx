# Credits

SNL NX separates work on the model from paid outputs. The balance and the nearest expiry date are in the user menu.

## Free

These do not use credits:

- creating, opening, importing and editing the project, and reading the import report;
- requesting the site seismic parameters and applying the proposed kh and kv;
- **calculating**, as many times as you like;
- reading results, checks and diagrams, and viewing the on-screen drawings;
- saving the `.snlnx` and using GeoDropbox.

## With credits

| Action | Credits |
|---|---:|
| Word report | 10 |
| DXF drawing | 10 |
| One message to the assistant | 3 |

Rates may change: the cost shown at the time of use is the reference.

## If something goes wrong

A **failed operation is not charged**: a document not generated, an empty file, a service error, an assistant message that ended in error or without an answer.

If the balance is not enough, the reason appears with the available balance and the link to buy credits. The project stays in the session: top up and try again.

## Repeating the same output

Downloading the same document again with the same data is not charged again when the service recognises the operation already confirmed. If you change the data that go into the document, the output is new.

After a change to the inputs the result becomes out of date: calculate again before the report.

## Assistant

Each message sent to the assistant costs 3 credits, quick actions and questions on the manual included. The analysis that the assistant runs for you is free, like the button. If the session has expired, another message is in progress or the monthly limit has been reached, the message is not sent and not charged. See [AI assistant](assistente.md).

## Credit expiry

Credits expire. The user menu shows the expiry of the nearest pack and highlights it when it gets close. General conditions are in the [Terms of service](https://geostru.ai/en/terms-of-service/).
