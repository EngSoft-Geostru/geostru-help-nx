# Salvataggio e formati

| Formato | Uso |
|---|---|
| `.pdmnx` | Apertura e salvataggio del piano NX con immagini e logo |
| `.pdm` | Importazione del piano desktop; le immagini vanno aggiunte nuovamente |
| `.xml` | Importazione del formato di scambio PDM supportato |
| `.docx` | Esportazione della relazione modificabile |
| `.png`, `.jpg`, `.jpeg` | Immagini di opere, unità, elementi e logo |

## File locale

Dal menu File scarica il `.pdmnx` e conserva una copia sul tuo dispositivo. Per riaprire il lavoro usa Apri. Un file corrotto viene rifiutato senza sostituire il piano attivo.

Nuovo, Apri ed Esempio possono sostituire il lavoro: salva una copia prima di confermare.

## GeoDropbox

Il pulsante GeoDropbox permette di aprire e salvare il piano nel tuo spazio cloud, secondo i permessi e i limiti del servizio. Verifica il completamento del salvataggio prima di chiudere il browser.

## Sessione del browser

Il piano attivo è temporaneo: 30 minuti di inattività o un riavvio dell'app possono interrompere la sessione. PDM segnala la scadenza; riapri il file salvato per continuare.

## Compatibilità

L'XML supportato è quello di scambio PDM, non un XML generico. L'import dei file desktop recupera dati testuali e struttura; non garantisce che ogni contenuto legacy sia pronto per la consegna. Rivedi le schede e aggiorna i riferimenti normativi dove necessario.
