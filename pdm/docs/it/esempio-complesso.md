# Esempio di un PDM complesso

Il caso descrive un **centro polifunzionale dimostrativo** con edificio, reti di servizio, viabilità, arredo urbano e verde. Tutti i dati identificativi sono fittizi: serve a esplorare l'app e la relazione.

| Contenuto | Quantità |
|---|---:|
| Opere | 5 |
| Unità tecnologiche | 20 |
| Elementi tecnici | 50 |
| Prestazioni | 149 |
| Anomalie | 203 |
| Controlli | 89 |
| Interventi | 163 |

## Aprire il caso

[Scarica il piano modificabile](samples/pdm-complesso.pdmnx){ .md-button }
[Consulta la relazione PDF](samples/pdm-complesso.pdf){ .md-button }

Apri PDM NX e importa il `.pdmnx` dal menu File. Esplora le schede e il cronoprogramma, poi scegli le sezioni nella pagina Relazione. Il PDF ha 344 pagine con indice aggiornato; l'impaginazione di una nuova esportazione può variare in base all'editor.

## Cosa resta da completare

Il caso mantiene 21 avvisi derivati dalle schede selezionate dell'archivio, fra cui cadenze, esecutori, descrizioni o modalità d'uso mancanti. Non sono stati assegnati dati tecnici arbitrari per cancellare gli avvisi.

Le cinque immagini sono schemi dimostrativi non in scala. Le schede devono essere adattate e verificate prima di usarle per un'opera reale.
