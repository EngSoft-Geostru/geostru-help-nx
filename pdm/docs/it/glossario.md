# Glossario

| Termine | Significato nel piano |
|---|---|
| Opera | Edificio, infrastruttura o insieme funzionale oggetto del piano |
| Unità tecnologica | Gruppo di componenti che svolge una funzione, come un impianto o un sistema strutturale |
| Elemento tecnico | Componente a cui si associano istruzioni, prestazioni, anomalie e manutenzioni |
| Prestazione | Caratteristica che l'elemento deve mantenere nel tempo |
| Anomalia | Manifestazione di degrado o malfunzionamento osservabile |
| Controllo | Verifica del livello prestazionale o dello stato dell'elemento |
| Intervento | Operazione di manutenzione per conservare o ripristinare il componente |
| Cadenza | Periodicità prevista per un controllo o un intervento |
| Cronoprogramma | Rappresentazione temporale delle attività previste |
| Frontespizio | Copertina con dati dell'opera e identificazione del professionista |
| Piano NX | File `.pdmnx` che conserva struttura, schede e immagini modificabili |
