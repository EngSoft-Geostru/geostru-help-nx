# Resources and sample files

From this page you can download the reference figures, the CAD drawing and the legacy manual cited in the Rock Mechanics NX manual.

## Figures and drawings

The drawings illustrate the geometric quantities used in the stability verifications and in the impact-force utility. You can print them or attach them to your report.

- [Figure 1 — planar sliding with a horizontal upper face (PDF)](../it/risorse/figura-1-scivolamento-planare.pdf)
- [Figure 2 — retention basin, significant quantities (PDF)](../it/risorse/figura-2-bacino-ritenuta.pdf)
- [Figure 3 — slope with an inclined upper face (PDF)](../it/risorse/figura-3-fronte-inclinato.pdf)
- [Planar sliding — CAD drawing (DWG)](../it/risorse/scivolamento-planare.dwg)

## Legacy manual

- [Rock Mechanics manual — legacy version (PDF, IT)](../it/risorse/rock-mechanics-manuale-legacy-it.pdf)

This is the original manual of the desktop version of Rock Mechanics, kept as a reference: some formulations and tables are described there in greater detail. However, for using the web app, always rely on this NX manual, which describes its current interface and workflows.

!!! tip "Complementary calculations online"
    For quick estimates outside the Rock Mechanics workflow — for example conversions or one-off checks — you can use the online apps of [Geoapp](geoapp.md), which can be used from a browser without installation.
