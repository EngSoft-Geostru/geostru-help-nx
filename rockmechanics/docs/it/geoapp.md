# Geoapp — calcoli online

**Geoapp** è la suite web di GeoStru per i calcoli online: oltre 40 applicazioni per ingegneria, geologia, geofisica, idrologia e idraulica. La maggior parte sono gratuite; alcune richiedono una sottoscrizione mensile o annuale.

## Perché la subscription

La sottoscrizione consente di:

- usare le applicazioni professionali ovunque e su qualunque dispositivo;
- salvare i file in cloud e sul proprio PC;
- riaprire i file per elaborazioni successive;
- stampare relazioni ed elaborati grafici;
- ricevere notifica e inclusione automatica delle nuove applicazioni nel proprio abbonamento;
- disporre sempre delle versioni aggiornate;
- accedere all'assistenza tramite ticket.

## Applicazioni utili con Rock Mechanics

Tra le applicazioni Geoapp, diverse si abbinano bene al flusso di Rock Mechanics NX:

- Scivolamenti lungo un piano
- Cunei 3D
- Chiodature (barre passive)
- Tiranti
- Sistemi di reti ancorate
- Barriere paramassi rigide ed elastiche
- Analisi di stabilità di superfici piane

[Vai su Geoapp](https://geoapp.geostru.eu){ .md-button }

!!! tip "Progetto degli interventi"
    Per i cinematismi a due giunti e per il dimensionamento degli interventi (chiodi, tiranti, reti) su rottura planare puoi usare anche [RockPlane NX](https://help.nx.geostru.ai/rockplane/it/).
