# Stratigrapher NX — Colonne stratigrafiche

**Stratigrapher NX** è il software web GeoStru per la creazione di **colonne
stratigrafiche** di sondaggi geotecnici. Gestisce stratigrafia, prove in sito
(SPT, DPSH, CPT/CPTU), piezometri, inclinometri, foto delle carote.
Esportazioni in PDF impaginato + JSON di interscambio (compatibile con
GeoSection NX e Liquefaction NX).

[**Apri Stratigrapher NX**](https://nx.geostru.ai/stratigrapher/){ .md-button .md-button--primary }
[Quickstart in 5 minuti](quickstart.md){ .md-button }

---

## Cosa fa, in sintesi

- **Colonne stratigrafiche** standardizzate (ISO 14689 / UNI 7029)
- **Prove in sito**: SPT, DPSH, CPT/CPTU, Vane Test, Pressiometro
- **Piezometri** con letture progressive nel tempo
- **Inclinometri** con grafici dei delta lungo la verticale
- **Foto carote** per documentazione sondaggio
- **Esportazioni**: PDF impaginato, JSON `.borehole` per altri prodotti NX

## Per chi

- **Geologi** che producono cassette di carote da campagne di sondaggio
- **Ingegneri geotecnici** che restituiscono i log di sondaggio nelle relazioni
- **Imprese di sondaggio** che documentano il sondaggio per il committente
- **Studi tecnici** che integrano i sondaggi in pareri di sottosuolo

## Come iniziare

1. Apri [`nx.geostru.ai/stratigrapher/`](https://nx.geostru.ai/stratigrapher/)
2. Carica un **template** (DPSH / CPTU / Inclinometro / Piezometro / Standard)
   o un esempio
3. Inserisci i dati: ubicazione, stratigrafia, prove
4. Allega le foto delle carote
5. Esporta in **PDF** o **JSON** per altri prodotti NX
