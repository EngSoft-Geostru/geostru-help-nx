# Credits

SPW NX separates work on the model from paid outputs. The balance and nearest expiry are visible in the user menu.

## Free

These actions use no credits:

- creating, opening and editing the project;
- importing a `.spwx` and reading the report;
- requesting site seismic parameters;
- calculating and viewing progress;
- reading diagrams, envelopes, checks and reinforcement;
- viewing drawings and report preview;
- saving the `.spwnx` and using GeoDropbox for the project.

## Paid actions

| Action | Credits |
|---|---:|
| Word report | 10 |
| DXF drawing | 10 |
| Opening the drawing in CAD Tools | 10 |
| One assistant message | 3 |

Rates may change. The cost shown by the command at the time of use is the reference for the operation.

Transferring data to Computo NX and PDM NX is not charged by SPW. The report preview is free.

## If something goes wrong

A **failed operation is not charged**. This applies to a document not generated, an empty file, a service error or an assistant message ending in error.

If the balance is insufficient, the reason appears with the available balance and the link to buy credits. The project remains in the session. Top up and try again.

## Repeating the same output

Generating the same document again with the same data does not cause a new charge when the service recognises the previously confirmed operation. If you change data included in the document, the output is new.

After an input change, the result may become out of date. Calculate again before generating the report or results DXF.

## Assistant

Every message sent to the assistant has a cost. Quick actions and questions about the manual follow the same rule.

If the session has expired, another message is running or the monthly limit has been reached, the message is not charged. See [Assistant](assistente.md).

## Credit expiry

Credits expire. The user menu shows the nearest package expiry and highlights it when close. Check the [Terms of Service](https://geostru.ai/en/terms-of-service/) for the general conditions.
