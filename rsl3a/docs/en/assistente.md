# AI assistant

The **Assistant** button opens the chat. The assistant is an artificial intelligence system that works on your project: it reads
regularisation, NTC spectrum, conditions and outcome, explains them and, when you ask, sets general data, nominal life and class, categories and
periods. If you attach the MS3 spectrum file or a report with the parameters, it writes them into the project.

- The engine computes the numbers: the assistant reads and quotes them, it does not estimate them.
- The spectrum and the parameters already present are replaced only if you ask for it explicitly.
- It does not generate the report (it uses credits: you download it yourself) and it does not delete anything.
- After a change made by the assistant, the page updates itself.

Each message uses NX credits; a message that ends in an error is not charged. From the chat you can also open a support ticket.
