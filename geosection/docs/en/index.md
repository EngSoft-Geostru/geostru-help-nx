# GeoSection NX — User manual

**GeoSection NX** is the GeoStru web tool for building **structured geological
cross-sections**. From a section trace (polyline on map) and the available
boreholes, it reconstructs a 2D section with stratigraphy, soil tables and
standardised geological symbols.

[**Open GeoSection NX**](https://nx.geostru.ai/geosection/){ .md-button .md-button--primary }
[5-minute quickstart](quickstart.md){ .md-button }

---

## What it does, in short

- **2D section** along a polyline with graduated axes (metres, elevations).
- **Boreholes** placed along the section with coloured strata.
- **Water table** drawn as a separate blue line.
- **Soil table** auto-generated.
- **Geological symbology** to ISO/UNI standards.
- **Export**: SVG, DXF, paginated PDF.

## Who it's for

- **Geologists** producing geological sections for sub-soil reports.
- **Geotechnical engineers** who include sections in foundation reports.
- **Consulting firms** for building, retaining-wall and excavation reports.

## Getting started

1. Open [`nx.geostru.ai/geosection/`](https://nx.geostru.ai/geosection/).
2. Load an example or create a new project.
3. Draw the **section trace** on the map (polyline).
4. **Add boreholes** with coordinates + stratigraphy.
5. **Generate the section** automatically.
6. Export to **SVG / DXF / PDF**.
