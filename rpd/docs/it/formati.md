# Formati file ed esportazione

## Progetto: file `.rpdnx`

Il progetto RPD NX si salva in un file **`.rpdnx`** (formato JSON) che contiene tutti i dati: dati generali, geometria, stratigrafia, sottofondo, traffico, geogriglia e metodo.

Dal menu **File**:

- **Nuovo** — riparte da un progetto vuoto (chiede conferma se ci sono modifiche non salvate);
- **Apri** — carica un `.rpdnx` dal computer;
- **Salva** — scarica il progetto come `.rpdnx`.

!!! note "Badge «Non salvato»"
    Quando modifichi i dati, accanto ai menu compare il badge **Non salvato**. Prima di *Nuovo* o *Apri*, RPD NX ti avvisa se ci sono modifiche non salvate. Il badge sparisce dopo il salvataggio.

## GeoDropbox

Con **GeoDropbox** (icona nella barra in alto) salvi e riapri i progetti dal **cloud GeoStru**, per ritrovarli da qualsiasi dispositivo.

## Relazione di calcolo

Dal menu **Relazione** generi il documento di calcolo completo:

- **Word (.docx)**
- **PDF (.pdf)**

La relazione riporta i dati di progetto, il metodo, i risultati e le grandezze di verifica.

## Esportazione della sezione

Dal menu **Esporta**:

- **Progetto (.rpdnx)** — lo stesso del salvataggio;
- **Sezione 2D (.svg)** — il disegno vettoriale della sezione trasversale, riutilizzabile in altri programmi o nella relazione.

## Progetti di esempio

Dal modal informazioni dell'app (menu **?** → *Risorse*) puoi scaricare progetti di esempio già pronti:

- `aashto.rpdnx` — esempio con il metodo empirico AASHTO 1993;
- `ivanov.rpdnx` — esempio con il metodo razionale di Ivanov.

Aprili con **File → Apri** per esplorare un caso reale.
