# Report and exports

Loadcap NX is not only a calculator: it produces the narrative **geotechnical
report**, structured according to the Italian Circolare 7/2019, ready for delivery.

## The geotechnical report

The **Report** tab shows a preview of the document as a "sheet", with a header and
numbered chapters:

1. Foreword
2. Geotechnical model and stratigraphy
3. Seismic hazard and actions
4. Design actions
5. Bearing-capacity check (ULS-GEO)
6. Settlements (SLS)
7. Conclusions

The **narrative chapters** (foreword, description of the work, site, geological
model, investigations, prescriptions, conclusions) have default texts from the
Circolare template, **editable** and individually toggleable; they alternate with
the computed chapters, with automatic numbering.

!!! note "Preview with no charge"
    The HTML preview of the report regenerates **for free**; only the export to
    Word/PDF consumes credits.

### Figures in the schemes

In the Report view you can choose which **schemes** to include (stratigraphic
section, bulb, map, contact pressures): they are inserted at the right points of
the document and also included in the Word/PDF export.

## Exports

| Format | Where | What |
|---|---|---|
| **Word (.docx)** | Report menu | Complete geotechnical report |
| **PDF** | Report menu | Report in PDF |
| **.lcnx** | File menu | Loadcap project (save/open) |
| **SVG** | 2D section | Section drawing |
| **CSV** | Loads | Load combinations |

## Saving and GeoDropbox

From the **File** menu you save and reopen the project in **.lcnx** format.
Projects can also be stored on **GeoDropbox**, the cloud space of the GeoStru NX
suite, to retrieve them from any workstation.

!!! tip "File → New"
    **File → New** creates a clean project. If you have unsaved changes, Loadcap
    asks for confirmation before replacing them (see the dot on the File button).
