# Example projects

Loadcap NX includes ready-to-use example projects, some of which **reproduce
validation tests** taken from the literature or from the desktop version. Download
them from the menu **?** (top) → **Resources** tab → *Example projects*, then open
them with **File → Open**.

| Example | Content |
|---|---|
| **Pad footing — NTC 2018** | Introductory base case: pad footing with NTC 2018 combinations |
| **Strip footing on multi-layer soil** | Strip footing on a non-uniform stratigraphy |
| **Circular Ø10 — Burland & Burbidge** | Validation of settlements with the Burland & Burbidge method |
| **Raft 2.5×2.5 — ex. 6.3.2** | Bearing capacity + settlements (oedometric and Schmertmann) |
| **Pad footing 4×4 — Lancellotta ex. 9.2** | Bearing capacity, sliding check and settlements |

## How to use them

1. Open the menu **?** and go to **Resources**.
2. Download the `.lcnx` file you need.
3. In Loadcap, **File → Open** and select the file.
4. Press **Compute** and compare the results.

!!! tip "Learn from solved cases"
    The validation files are the quickest way to understand how to set up a type of
    analysis: they come already configured (geometry, stratigraphy, combinations,
    calculation options) and their results are comparable with the references.

!!! note "Sliding check"
    The *Pad footing 4×4 — Lancellotta ex. 9.2* example includes an action such
    that the sliding check on the founding plane is exercised, in addition to
    bearing capacity and settlements.
