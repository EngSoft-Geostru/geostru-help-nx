# Glossary

| Term | Definition |
|---|---|
| **Stem** | the vertical (or inclined) wall; the **back face** is the one in contact with the backfill |
| **Toe / heel** | the two parts of the foundation in front of and behind the stem |
| **Shear key** | downward projection under the foundation that increases sliding resistance |
| **Downhill shelf** | cantilever on the downhill side of the stem, for example to support a slab |
| **Lean concrete** | layer of blinding concrete under the foundation |
| **Backfill** | the soil retained uphill of the wall |
| **Virtual back** | the vertical through the end of the heel, on which the thrust is computed for the global checks |
| **Earth pressure coefficient** (K~a~, K~0~, K~p~) | ratio between horizontal and vertical stress in the soil in active, at-rest or passive conditions |
| **Wall friction angle** (δ) | inclination of the thrust to the normal to the face |
| **Mononobe-Okabe** | pseudo-static method for the earth pressure under seismic conditions |
| **k~h~, k~v~** | horizontal and vertical seismic coefficients: seismic forces are the weight times these coefficients |
| **β~m~** | reduction coefficient of the maximum expected acceleration at the site for retaining structures (NTC 2018 §7.11.6.2.1) |
| **Combination** | set of partial factors on actions (A), soil parameters (M) and resistances (R) |
| **EQU** | limit state of equilibrium as a rigid body: for the wall, overturning |
| **GEO / STR** | limit states of the ground (sliding, bearing capacity) and of the structure (strength of the sections) |
| **Safety factor** (F~s~) | ratio between design resistance and action; the check is satisfied if F~s~ ≥ 1 (with the R factors already applied) |
| **Eccentricity** (e) | distance of the resultant of the loads from the centre of the base |
| **Effective width** (B′) | B − 2e: the part of the base on which bearing capacity is computed under eccentric load |
| **Kern** | central zone of the base (B/3 wide) where the resultant leaves the whole base in compression |
| **Envelope** | for each section, the maximum and minimum internal forces over all combinations |
| **Bar schedule** | list of bars with position, diameter, number, length, shape and weight |
| **Rigid cap** | model of the pile foundation as a non-deformable body that distributes the actions among the rows |
| **Pile row** | piles aligned parallel to the wall, with their spacing |
| **Grout body** | the grouted length of the anchor that transfers the load to the soil |
| **Free length** | length of the anchor between head and grout body, which transfers no load to the soil |
| **Calculation code** | block of the report required by §10.2 of NTC 2018: identifies software, version and document |
