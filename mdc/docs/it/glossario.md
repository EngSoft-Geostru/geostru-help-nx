# Glossario

| Termine | Definizione |
|---|---|
| **Paramento** | la parete verticale (o inclinata) del muro; il paramento **interno** è quello a contatto con il terrapieno |
| **Suola di valle / di monte** | le due parti della fondazione davanti e dietro al paramento (piede e tallone) |
| **Dente** | sporgenza verso il basso sotto la fondazione che aumenta la resistenza allo scorrimento |
| **Mensola a valle** | sbalzo sul lato di valle del paramento, per esempio per sostenere una soletta |
| **Magrone** | strato di calcestruzzo magro sotto la fondazione |
| **Terrapieno** | il terreno trattenuto a monte del muro |
| **Piano virtuale** | la verticale per l'estremo della suola di monte, su cui si calcola la spinta per le verifiche globali |
| **Coefficiente di spinta** (K~a~, K~0~, K~p~) | rapporto fra la pressione orizzontale e quella verticale del terreno in condizioni attive, a riposo o passive |
| **Angolo d'attrito terra-muro** (δ) | inclinazione della spinta rispetto alla normale al paramento |
| **Mononobe-Okabe** | metodo pseudostatico per la spinta del terreno in condizioni sismiche |
| **k~h~, k~v~** | coefficienti sismici orizzontale e verticale: le forze sismiche sono il peso per questi coefficienti |
| **β~m~** | coefficiente di riduzione dell'accelerazione massima attesa al sito per le opere di sostegno (NTC 2018 §7.11.6.2.1) |
| **Combinazione** | insieme di coefficienti parziali su azioni (A), parametri del terreno (M) e resistenze (R) |
| **EQU** | stato limite di equilibrio come corpo rigido: per il muro, il ribaltamento |
| **GEO / STR** | stati limite del terreno (scorrimento, carico limite) e della struttura (resistenza delle sezioni) |
| **Fattore di sicurezza** (F~s~) | rapporto fra resistenza di progetto e azione; la verifica è soddisfatta se F~s~ ≥ 1 (con i coefficienti R già applicati) |
| **Eccentricità** (e) | distanza della risultante dei carichi dal centro della base |
| **Larghezza efficace** (B′) | B − 2e: la parte di base su cui si calcola il carico limite con carico eccentrico |
| **Nocciolo d'inerzia** | zona centrale della base (larga B/3) in cui la risultante lascia la base tutta compressa |
| **Inviluppo** | per ogni sezione, il massimo e il minimo delle sollecitazioni su tutte le combinazioni |
| **Distinta dei ferri** | elenco delle barre con posizione, diametro, numero, lunghezza, sagoma e peso |
| **Plinto rigido** | modello della fondazione su pali come corpo indeformabile che ripartisce le azioni fra le file |
| **Fila di pali** | pali allineati parallelamente al muro, con il loro interasse |
| **Bulbo** | tratto cementato del tirante che trasmette il tiro al terreno |
| **Tratto libero** | tratto del tirante fra la testa e il bulbo, che non trasmette forza al terreno |
| **Codice di calcolo** | blocco della relazione richiesto dal §10.2 delle NTC 2018: identifica software, versione e documento |
