# Relazione ed esportazioni

Dopo un calcolo con esito, SRS NX genera il documento di relazione con i
dati di progetto, i passaggi di calcolo e l'esito delle verifiche.

## Esportare la relazione

Dal menu **Relazione** della toolbar scegli il formato:

| Formato | Note |
|---|---|
| **Word (.docx)** | sempre disponibile |
| **PDF** | disponibile se il servizio di conversione è attivo |
| **DOC** | disponibile se il servizio di conversione è attivo |

Le voci del menu restano disabilitate finché non hai eseguito un calcolo con
risultati: esegui **Calcola** prima di esportare.

!!! note "L'esportazione consuma crediti"
    Generare la relazione (in qualunque formato) consuma crediti NX, come il
    calcolo.

## Salvataggio del progetto

Dal menu **File**:

- **Nuovo** — svuota la form e riparte da un progetto vuoto.
- **Salva** — scarica il progetto corrente in un file **.srs**.
- **Apri** — carica un file **.srs** salvato in precedenza (o uno dei
  [progetti di esempio](esempi.md)).

## GeoDropbox

Il pulsante **GeoDropbox** in toolbar salva e recupera i progetti dallo
spazio cloud condiviso della suite GeoStru NX, per ritrovarli da qualsiasi
postazione senza scaricare e ricaricare manualmente il file `.srs`.
