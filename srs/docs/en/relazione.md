# Report and exports

After a successful calculation, SRS NX generates the report document with
the project data, calculation steps and the outcome of the checks.

## Exporting the report

From the toolbar's **Report** menu choose the format:

| Format | Notes |
|---|---|
| **Word (.docx)** | always available |
| **PDF** | available if the conversion service is active |
| **DOC** | available if the conversion service is active |

The menu entries stay disabled until you have run a calculation with
results: run **Calculate** before exporting.

!!! note "Exporting consumes credits"
    Generating the report (in any format) consumes NX credits, just like
    the calculation.

## Saving the project

From the **File** menu:

- **New** — clears the form and starts from an empty project.
- **Save** — downloads the current project as an **.srs** file.
- **Open** — loads a previously saved **.srs** file (or one of the
  [example projects](esempi.md)).

## GeoDropbox

The **GeoDropbox** button in the toolbar saves and retrieves projects from
the GeoStru NX suite's shared cloud storage, so you can find them from any
workstation without manually downloading and re-uploading the `.srs` file.
