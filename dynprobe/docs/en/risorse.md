# Resources and sample files

## Project files (.dypx)

Download a ready-made complete case and open it from the Dynamic Probing NX Home with **Import .dypx…**.

| File | Content |
|---|---|
| [ex-completo.dypx](../samples/ex-completo.dypx) | 10 tests (DPM, DPSH, borehole SPT), 23 embedded instruments, stratigraphy with cohesive and non-cohesive soils, pre-set correlations |
| [ex-acme-9prove-dpsh.dypx](../samples/ex-acme-9prove-dpsh.dypx) | 9 continuous DPSH tests on a ~20 m grid, embedded BORRO instruments |

## Datalogger files (.csv)

Use with **Import readings from file…** in the Readings tab of a new continuous test.

| File | Content |
|---|---|
| [ex-bianco-pardesca-16m.csv](../samples/ex-bianco-pardesca-16m.csv) | Continuous profile 16 m at 0.20 m step (80 readings), coordinates in header, 5+ recognisable layers |

## Reference standards

- UNI EN ISO 22476-2 — Continuous dynamic penetration tests (DPL, DPM, DPH, DPSH)
- UNI EN ISO 22476-3 — Standard Penetration Test (SPT)
- NTC 2018 — Italian Technical Standards for Constructions (D.M. 17/01/2018)
- NTC 2008 — Italian Technical Standards for Constructions (D.M. 14/01/2008)
- EN 1997-1 (Eurocode 7) — Geotechnical design
- EN 1998-1 (Eurocode 8) — Design in seismic zones
