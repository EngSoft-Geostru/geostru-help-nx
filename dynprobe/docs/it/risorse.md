# Risorse e file di esempio

## File di progetto (.dypx)

Scarica un caso già completo e aprilo dalla Home di Dynamic Probing NX con **Importa .dypx…**.

| File | Contenuto |
|---|---|
| [ex-completo.dypx](../samples/ex-completo.dypx) | 10 prove (DPM, DPSH, SPT in foro), 23 strumenti embeddati, stratigrafia con coesivi e incoerenti, correlazioni preimpostate |
