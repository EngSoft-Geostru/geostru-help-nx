# Sample projects

From the **?** modal → **Resources** you can download the sample projects (.mre), to be
opened with File → Open:

- **Wall in design mode — NTC 2018** — the base case in the Design approach.
- **Wall in check mode with seismic action** — the Check approach with seismic action.
- **Facing battered at 60°** — geometry with an inclined facing.
- **Exercises from the GeoStru book on reinforced soil** — the H = 10 m wall of the worked
  exercises (γ = 17.3 kN/m³, φ = 34°, δ = 24°, PET 60/30 grid, 14 levels): useful to
  compare the results against a hand calculation.
- **Facing at 65° with seismic action and surcharge** — the case where the tieback/compound
  internal checks do the work.
