# Progetti di esempio

Dal modale **?** → **Risorse** puoi scaricare i progetti di esempio (.mre), da aprire
con File → Apri:

- **Muro in progetto — NTC 2018** — il caso base in approccio Progetto.
- **Muro in verifica con sisma** — approccio Verifica con azione sismica.
- **Paramento inclinato a 60°** — geometria con facciata inclinata.
- **Esercizi dal volume GeoStru sulle terre rinforzate** — il muro H = 10 m degli
  esercizi svolti (γ = 17,3 kN/m³, φ = 34°, δ = 24°, griglia PET 60/30, 14 livelli):
  utile per confrontare i risultati col calcolo manuale.
- **Paramento a 65° con sisma e sovraccarico** — il caso in cui lavorano le verifiche
  interne tieback/compound.
